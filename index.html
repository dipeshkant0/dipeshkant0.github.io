hft-orderbook-openmp ↗ Low-Latency / HFT
High-throughput financial analytics engine processing millions of bit-stuffed market feed packets in real-time.
  • Bit-Level Packet Decoding: Decodes 49-bit packed financial order packets on the fly with custom bit-unstuffing routines.
  • Contention-Free Concurrency: Eliminates hash map lock contention by giving each thread private Thread-Local Storage (TLS) maps, merged via an O(log P) Parallel Tree Reduction.
  • Asynchronous Task Offloading: Disk snapshots and I/O writes are dispatched to background OpenMP task threads to keep order ingestion unblocked.
Scaling: 9.05x on 12-Thread Ryzen • Zero Mutex Contention
C++17 OpenMP Lock-Free TLS Bit-Unstuffing Tree Reduction
cuda-pointcloud-lhe ↗ GPU Acceleration
Sub-second 3D Point Cloud Local Histogram Equalization (N = 100,000) using massive GPU parallelism.
  • Shared Memory Tiling: Loads contiguous point chunks into on-chip shared memory tiles to bypass high-latency global VRAM reads.
  • Register Bypass Caching: Pins the max-heap root in a dedicated thread register during K-NN search (K = 128), preventing L1 cache thrashing.
  • Spatial Hash Coalescing: Hashes 3D points into a 1D grid using large coprimes and sorts on CPU before offload, ensuring coalesced warp reads.
  • Dynamic Block Reductions: Hierarchical warp and block-level reductions reduce atomic global contention by over 90%.
Runtime: 0.149s Execution Time • 6.47x Faster than 16-Thread OpenMP
CUDA C++ Shared Memory Register Bypass Spatial Hashing
distributed-clique-solver ↗ Distributed HPC
Distributed Branch-and-Bound solver for the NP-hard Budgeted Maximum Weight Clique problem using OpenMPI.
  • Zero-Allocation Memory Banking: Pre-allocates candidate vertex stacks up to maximum tree depth D_max, eliminating all runtime heap allocations.
  • Non-Blocking Bound Propagation: Broadcasts globally improving primal bounds via buffered sends (`MPI_Bsend`) paired with opportunistic polling (`MPI_Iprobe` every 8192 nodes).
  • 64-Bit Bitset SIMD Intersections: Candidate set intersections compute 64 potential graph vertex connections per CPU clock cycle.
Cluster Scaling: 8.27x on 16 Cores • 100.1% Super-Linear Efficiency
C++17 OpenMPI Zero-Allocation MPI_Bsend / Iprobe Bitsets
